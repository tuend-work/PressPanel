WordPress Lockdown (Bảo Vệ Bất Biến chattr +i)

Khi bật Lockdown, tệp `wp-config.php`, thư mục `wp-admin` và `wp-includes` được gắn cờ bất biến (`chattr +i`) và chuyển quyền chỉ đọc (`0444`). Bất kỳ hacker hay mã độc nào chiếm quyền thực thi PHP cũng KHÔNG THỂ ghi đè hay chèn backdoor vào source core!

Trình Quản Lý Tham Số wp-config.php (WP Defines)

Bộ Tối Ưu Hóa WordPress Độc Quyền (WPC Optimize MU-Plugins)

Các module tối ưu được nạp dưới dạng Must-Use Plugins (chạy tự động trước mọi plugin khác, không bị tắt bởi user trong wp-admin, không sinh database rác).

wpc-optimize-admin.php (Tối Ưu WP-Admin)
Dọn dẹp widget thừa, tắt thông báo phiền phức, tăng tốc độ load trang quản trị wp-admin
wpc-optimize-compatibility.php (Tương Thích PHP Mới)
Vá lỗi deprecated và tăng tính tương thích khi chạy plugin/theme cũ trên PHP 8.1, 8.2, 8.3
wpc-optimize-editor.php (Trình Soạn Thảo)
Tối ưu hiệu năng trình soạn thảo Block Gutenberg, tránh giật lag khi viết bài dài
wpc-optimize-flatsome.php (Tăng Tốc Flatsome Theme)
Tối ưu hoá đặc biệt cho giao diện Flatsome và WooCommerce, giảm query database thừa
wpc-optimize-frontend.php (Tối Ưu Tốc Độ Khách Xem)
Loại bỏ query string khỏi static assets, tắt biểu tượng emoji không dùng, trì hoãn JS
wpc-optimize-media.php (Tối Ưu Hình Ảnh)
Giới hạn kích thước upload ảnh khổng lồ, ngăn sinh quá nhiều size thumbnail thừa thãi
wpc-optimize-security.php (Lá Chắn Bảo Mật Sâu)
Giấu phiên bản WordPress, vô hiệu hóa XML-RPC, chặn quét username tác giả (?author=1)
